# Astroplate - a free Astro starter template with TailwindCSS & TypeScript to kickstart your project fast.

#### Preview

 - [Demo](https://themewagon.github.io/astroplate/)

#### Download
 - [Download from ThemeWagon](https://themewagon.com/themes/astroplate/)

## Getting Started

1. Clone Repository
```
git clone https://github.com/themewagon/astroplate.git
```
2. Install Dependencies
```
npm i
```
3. Run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```
